Frequently Asked Questions

Everything You Need to Know

How does `contrib-cli` achieve 95% bandwidth savings?

Standard `git clone` downloads every historical file blob across all commits. `contrib-cli` uses Git’s native `--filter=blob:none` flag to fetch only tree metadata, downloading files strictly on-demand as you access or edit them.

How is this different from `git worktree`?

`git worktree` requires you to already have a local full copy of the repository downloaded. `contrib-cli` handles initial remote fetching without requiring a local base clone, integrates GitHub issue parsing, and sets up isolated workspaces end-to-end.

Which IDEs and Editors are supported?

`contrib-cli` includes built-in launchers for Antigravity IDE (`--antigravity`), VS Code (`--vscode`), Neovim (`--nvim`), Vim (`--vim`), Helix (`--helix`), Zed (`--zed`), Cursor (`--cursor`), and WebStorm (`--webstorm`).
